LSwitcher живёт в строке меню и помогает исправлять слова, набранные в другой раскладке. Работает локально, без регистрации. Обработка текста полностью локальная; ручная проверка обновлений обращается к GitHub.

## Два способа исправления

| Режим | Как работает |
| :--- | :--- |
| **Автоматически** | Проверяет слово после пробела, Enter или Tab и исправляет уверенно распознанную ошибку раскладки. |
| **Двойной Shift** | Дважды быстро нажмите одну и ту же клавишу Shift, чтобы преобразовать слово перед курсором или выделенный текст. |

В Termius двойной Shift исправляет только что набранное слово до пробела или отправки команды. Выделение вывода терминала не заменяется. Защищённый ввод macOS блокирует перехват клавиатуры.

Можно выбрать любой Shift, только левый или только правый. Удержание Shift и обычный набор заглавных букв не запускают исправление.

Выделите слово или предложение и нажмите Shift дважды — преобразуется всё выделение. Ручное исправление работает и после пробела.

## Удобно каждый день

- **Восстановление после сна.** Обработчик клавиатуры и значок строки меню пересоздаются после пробуждения и разблокировки. Контроль состояния восстанавливает отключённый или недействующий обработчик. В диагностике показаны поколение обработчика и Secure Input.

- **Значок строки меню на выбор.** В разделе «Переключение» выберите стрелки (по умолчанию), код раскладки RU/EN или флаг. Код и флаг обновляются при смене текущей раскладки; выбор сохраняется после перезапуска.

- **Флаг у текстового поля.** Маленькая подсказка текущей раскладки появляется при получении фокуса и скрывается с началом ввода. Она не перехватывает клики или клавиатуру; опция «Флаг раскладки у поля» находится в разделе «Переключение». Защищённые и недоступные через Accessibility поля пропускаются. Для подсказки читаются только роль и координаты поля, без его содержимого.

- **Отмена автозамены.** Backspace после исправления с пробелом возвращает исходное слово в течение 5 секунд, если поле и курсор не изменились. При недоступных данных Accessibility Backspace работает обычно.
- **Личные исключения слов.** В разделе «Исключения» добавьте до 5 000 слов, по одному в строке. Они не исправляются автоматически; двойной Shift остаётся доступен.

- **Исключения приложений.** Отключите автоматическое исправление там, где оно мешает. Ручной двойной Shift остаётся доступен.
- **Расширенный словарь RU/EN.** Около 81 тысячи записей с частотами и проверкой словоформ. Неоднозначные корректные слова сохраняются.
- **Настройки под macOS.** Светлая и тёмная темы, отдельные разделы переключения, исключений и диагностики.
- **Пауза в один шаг.** Управление из строки меню.
- **Без истории набора.** Приложение не ведёт журнал введённых слов и не отправляет текст в сеть.

## Установка

1. Скачайте DMG из [последнего релиза](https://github.com/sadus174/LSwitcher/releases/latest).
2. Перетащите **LSwitcher.app** в **Applications** и запустите приложение оттуда.
3. В разделе **«Доступ и диагностика»** разрешите **«Универсальный доступ»** и **«Мониторинг ввода»**.
4. Нажмите **«Проверить снова»**. При необходимости перезапустите приложение.

> **Текущая сборка подписана локальной ad-hoc подписью и не нотариализована Apple.** macOS может заблокировать первый запуск. Для доверенной вами копии используйте системную кнопку «Всё равно открыть» в разделе «Конфиденциальность и безопасность». После обновления локальной сборки может потребоваться повторная выдача разрешений.

Архитектура установщика указана в описании релиза. Для автозапуска добавьте LSwitcher в системные **«Объекты входа»**.

## Обновления

Откройте **«О программе» → «Проверить обновления»**. Приложение проверит последний стабильный релиз на GitHub. Если доступен подписанный пакет, нажмите **«Скачать обновление»**, затем **«Установить и перезапустить»**. Проверяются закреплённая подпись Ed25519, SHA256, версия и архитектура. Установщик повторно проверяет пакет и подпись приложения, ждёт завершения старого процесса и сохраняет предыдущую копию. При недоступной для записи папке используйте DMG. Повышение привилегий и отключение защиты macOS не используются. Фоновых сетевых проверок нет.

Встроенная установка появляется в 0.4.1 и применяется к последующим версиям. Переход с 0.3.x выполняется вручную. Закрытый ключ обновлений не входит в приложение или репозиторий. Подпись пакета не заменяет Developer ID и нотариализацию: macOS может потребовать повторную выдачу разрешений после обновления.

## Приватность

Текущее слово временно обрабатывается в оперативной памяти; буфер ограничен 80 символами и очищается при завершении слова, смене поля и других действиях. Для ручного исправления приложение читает выделение или содержимое поля через Accessibility. Эти данные не записываются в файлы и журналы.

Для отмены в оперативной памяти также хранится последняя автозамена, доступная для отката в течение 5 секунд. Сохраняются только настройки: включение, автоматический режим, выбранный Shift, исключения приложений и явно добавленные пользователем слова. Диагностика показывает счётчики и статусы текущего запуска без введённых слов. Встроенная проверка создаёт отдельный временный документ с тестовым текстом в TextEdit.

Защищённые поля и Secure Input пропускаются; 1Password исключён из обработки. Распознавание нестандартных полей паролей сторонних приложений не гарантируется.

## Сборка из исходников

Требуются macOS 13+ и Swift 6 из Xcode или Command Line Tools.

```sh
git clone https://github.com/sadus174/LSwitcher.git
cd LSwitcher
swift build -c release
swift run -c release LSwitcherChecks
```

Репозиторий содержит код, тесты и необходимые ресурсы, включая готовый словарь. Локальные ключи, служебные скрипты, исходные корпуса, отчёты и готовые сборки в Git не публикуются. Установочный DMG находится в Releases.

Для проверки установленного приложения откройте **«Доступ и диагностика» → «Проверить ввод»**. Во время проверки не переключайте окна и не вводите текст. Выберите TextEdit, Safari или Chrome. Проверяются оба Shift, автоматическое исправление в обе стороны, отмена, личные исключения, адреса, курсор, приостановка обработчика и выделение; исходные настройки восстанавливаются. Браузерные тесты используют локальную страницу.

## Ограничения

Поддерживается стандартное соответствие клавиш **QWERTY ↔ ЙЦУКЕН**. Это исправление раскладки, а не орфографии или перевода. Ручное исправление зависит от поддержки macOS Accessibility редактором. IME и нестандартные текстовые поля требуют отдельной проверки. Терминалы и известные менеджеры паролей по умолчанию исключены из автоматического режима.
