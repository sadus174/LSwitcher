# Проверка реализации

## Текущее состояние 0.7.0

Реализованы в исходниках быстрые исключения приложений, единый текущий статус, явное личное исключение после принятой отмены и системный автозапуск. Реализация не равна завершению всех проверок: открытые задачи в tasks.md сохраняются до выполнения указанной в них проверки.

### Сквозной результат первого этапа

После подтверждения пользователя для тестирования создан отдельный bundle `com.lswitcher.preview` с именем LSwitcher Preview. Выданы Accessibility и Input Monitoring обычным системным способом; после перезапуска подтверждены оба разрешения, право отправки событий и активный обработчик. Основная `/Applications/LSwitcher.app` не заменялась.

На сборке первого этапа через CUA запущен встроенный TextEdit-тест: **40/40**. В числе проверок — реальный маршрут подготовки/действия NSMenu, отключение автоисправления исключением, ручной Shift в исключённом приложении и возвращение автоматики после снятия. Это подтверждает первый этап; последующие изменения статусов, кандидата и автозапуска этим прогоном не покрыты.

### Программные проверки новых функций

- LSwitcherChecks: приоритеты статусов, неизвестное/неподдерживаемое/защищённое поле, независимая защита 1Password; кандидат одного слова, 60 секунд, очистка по смене приложения/выключению/Secure Input/suspend/исправлению/завершению, сохранение при переходе в своё меню; нормализация и лимиты личных исключений. Пройдены.
- `--check-preferences`: реальное сохранение в отдельном временном UserDefaults-домене и чтение вторым процессом; явное добавление личного слова, дубликаты и отказ при лимите без потери прежних записей. Пройдено.
- `--check-exclusion-menu`: настоящие действия NSMenu и недоступные цели. Пройдено.
- `--check-login-launch`: подставная служба, отсутствие регистрации без действия пользователя, четыре системных статуса, внешние изменения, ошибки регистрации и маршрутизация синтетического login Apple event. Пройдено; реальную системную регистрацию не меняет.

### Выпуск и updater

- Локальный ad-hoc процесс сборки создаёт приложение 0.7.0, DMG, ZIP обновления и подписанный манифест. Ключ остаётся локально, содержимое не выводится.

Размер приложения — **2 609 757 байт** при лимите **2 687 792 байта**. Финальные файлы: `dist/LSwitcher.app`, `dist/LSwitcher-0.7.0.dmg`, `dist/LSwitcher-0.7.0-arm64.zip`, `dist/update.json`. Это локальные ad-hoc артефакты, не нотариализованный релиз.
- `test-release-workflow.py` прошёл: временные проекты и имитация Apple подтверждают ранний отказ при неверной конфигурации, ad-hoc путь, прикрепление билета до финального ZIP и корректный SHA256, остановку при отклонении Apple. Это **не** реальная нотариализация.
- `test-updater.py` прошёл на настоящем updater и временной копии: повреждённый ZIP и изменённые версия/архитектура/подпись манифеста отклоняются без изменения цели; корректный подписанный пакет устанавливается, предыдущая версия сохраняется, та же версия повторно не устанавливается.
- Проверка metadata связки ключей обнаружила **0** действующих Developer ID Application identities. Реальная подпись Developer ID, принятие Apple и переход с ad-hoc на нотариализованную сборку не выполнены; задачи 6.3–6.4 открыты.
- В Git допускаются только шесть необходимых обезличенных выпускных скриптов и RELEASING.md. Ключи, dist, корпуса и остальные служебные скрипты остаются игнорируемыми.

### Сквозная проверка полной сборки после разблокировки

Пользователь явно разрешил выключать/включать и при необходимости пересоздавать только записи `com.lswitcher.preview`. После ручной разблокировки Mac завершена Preview, сброшены только её Accessibility и ListenEvent, разрешения выданы через системный интерфейс и Preview перезапущена. Разрешения `com.lswitcher.app` не сбрасывались. Исторические отказы автоматической проверки относятся к попыткам до этого расширенного согласия; эти отклонённые действия не выполнялись.

На полной сборке 0.7.0 через встроенную кнопку и CUA пройдены TextEdit **46/46**, Safari **39/39**, Chrome **39/39**. Настройки после каждого прогона восстановлены. В Chrome первая попытка остановилась до ввода из-за неготового поля при запуске браузера; повторный прогон на загрузившемся браузере прошёл полностью. Проверены оба Shift, автоматические исправления, отмена, явное исключение слова и его срок, исключение приложения и ручной режим, статусы и восстановление обработчика. Сон/блокировка в этих тестах моделируются уведомлениями и не считаются физическими испытаниями.

### Системный автозапуск и обычное повторное открытие

Проверен настоящий `SMAppService.mainApp` в зарегистрированном Launch Services bundle `.build/preview/LSwitcher Preview.app`. Начальное состояние выключено/notFound. Переключатель приложения включил регистрацию; системные «Объекты входа» показали LSwitcher Preview. Запись удалена только для Preview через системный список; после возврата и повторного показа страницы приложение отразило выключенный статус. Затем выполнены повторная регистрация и unregister из приложения, итог — выключено/notRegistered. Основная копия не регистрировалась и не изменялась. Это проверка реального системного API для локального bundle, не фактического входа в систему и не Developer ID сборки.

Окно Preview закрыто, тот же bundle открыт через Finder/Cmd+O. Окно настроек вернулось, процесс остался **PID 7038**, поколение обработчика — **16**, счётчики и результат предыдущего smoke сохранились. Второго процесса и повторной установки обработчика не обнаружено. Разветвление Apple event для обычного/login запуска отдельно покрыто программными проверками.

### Открытые проверки и внешние ограничения

В Termius через File → New Local Terminal создан отдельный локальный сеанс. Существующая удалённая вкладка не использовалась для тестового ввода. CUA передал искажённые/неполные символы, а счётчик клавиатурных событий LSwitcher при этом не вырос; это не подтверждает прохождение обычного пути event tap. Enter не отправлялся. Созданная локальная вкладка закрыта через её собственную кнопку; успешное сквозное исправление в Termius **не заявляется**, задача 5.4 открыта. AX-free fixture в трёх smoke-прогонах прошёл, но реальную проверку Termius не заменяет.

Физический сон/пробуждение и реальный вход в отдельный сеанс **не проверены**. Текущий рабочий сеанс пользователя не завершался. Задача 4.4 остаётся открытой до реального входа. Spotlight подтверждён пользователем; нового исправления Spotlight не выполнялось.

После проверок Preview завершена через меню, установленная `/Applications/LSwitcher.app` 0.6.4 вновь открыта через CUA. Интерфейс подтвердил «Готов к работе», исходные переключатели включены и режим значка RU/EN сохранён.

Действующих Developer ID Application identities нет: задачи 6.3–6.4 остаются открытыми. Изменение OpenSpec не архивируется. Локальные ad-hoc артефакты не опубликованы; `/Applications/LSwitcher.app` не заменена.

## 27 октября 2026 — этап 1, промежуточный результат

Реализованы задачи 1.1–1.3: общий метод изменения исключений, динамический пункт NSMenu с сохранённой целью, отказ при недоступной/собственной/устаревшей цели. Снятие пользовательского исключения не меняет независимые ограничения Secure Input и менеджеров паролей в KeyboardEngine.

Проверено:

- `swift build -c release` — успешно. Сборка потребовала доступа к системному кэшу Swift/Clang; ограничения sandbox не являются ошибкой исходников. Linker сообщает о отсутствующих необязательных поисковых каталогах Command Line Tools, сборка завершается успешно.
- `.build/release/LSwitcher --check-preferences` — успешно: нормализация, общий путь добавления/удаления, отсутствие дубликатов, чтение настроек новым процессом. Использован отдельный временный домен UserDefaults, удалённый после проверки.
- `.build/release/LSwitcher --check-exclusion-menu` — успешно: настоящие действия NSMenu добавляют и снимают исключение для подготовленной цели; отсутствующая цель, собственный процесс и смоделированное исчезновение процесса отклоняются. Настройки пользователя не изменялись. Это программная проверка маршрута действия, а не физический тест клика в строке меню.
- `.build/release/LSwitcherChecks` — успешно: существующие проверки преобразования, жестов, исключений и курсора.
- `git diff --check` и `openspec validate improve-everyday-reliability --strict` — успешно.

Задача 1.4 пока открыта. SmokeTest расширен вызовом реального пути меню: исключение выключает автоисправление, сохраняет ручной Shift, снятие возвращает автоисправление; восстановление списка синхронизирует настройки. Перед проверкой выделения автоисправление временно отключается, поскольку раньше этот сценарий выполнялся внутри исключённого приложения.

Отдельная сборка подготовлена в `.build/preview/LSwitcher.app`, подпись `codesign --verify --strict` проверена. Установленная `/Applications/LSwitcher.app` не заменена. При открытии тестовой копии через CUA подтверждено: Универсальный доступ, Мониторинг ввода и отправка исправлений не разрешены; обработчик не запущен, кнопка проверки ввода недоступна. Ввод в тестовые или пользовательские поля не отправлялся.

Перед выдачей системных разрешений запрошено подтверждение пользователя. Сквозная проверка и остальные этапы не считаются выполненными.

Тестовая копия закрыта, установленный LSwitcher вновь запущен через CUA; интерфейс подтверждает «Готов к работе». Пользовательские исключения и остальные настройки не изменялись.

Проверка размера: первая промежуточная копия содержала неочищенный бинарник из SwiftPM и превышала лимит. После стандартного `strip -S -x`, как в процессе выпуска, и повторной ad-hoc подписи размер — 2 481 693 байта при лимите 2 687 792; проверка размера и подписи успешна.
