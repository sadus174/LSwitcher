# Proposal

## Why

Основные сценарии LSwitcher уже реализованы, но исключения требуют перехода в настройки, причины недоступности исправления не всегда очевидны, а автозапуск настраивается отдельно в macOS. Следующий выпуск должен сократить эти затруднения и подтвердить надёжность существующих сценариев.

## What Changes

- Добавить в меню исключение текущего приложения и обратное действие, сохранив ручной двойной Shift.
- Показывать единый актуальный статус в меню, подсказке значка и настройках, отдельно от последнего диагностического события.
- После отмены предложить явно добавить исходное слово в личные исключения; временный кандидат хранится только в памяти.
- Управлять системным автозапуском из настроек, без открытия окна при входе в систему.
- Проверить реальные сценарии сна/пробуждения и Termius, а также регрессии TextEdit/Safari/Chrome.
- Доработать и проверить существующий процесс Developer ID/нотариализации, включая пакет встроенного обновления.
- Не добавлять временную паузу, новые языки, историю ввода или облачные функции. Spotlight проверен пользователем; отдельное исправление не требуется.

## Capabilities

### New Capabilities

В проекте пока нет основных спецификаций OpenSpec. Существующие функции сохраняются; новые спецификации описывают только согласованный прирост поведения.

- `app-exclusion-menu`: управление исключением приложения из строки меню.
- `operation-status`: согласованные статусы доступности исправления.
- `word-exclusion-after-undo`: явное исключение слова после отмены.
- `login-launch`: управление автозапуском и поведение при входе.
- `release-trust`: проверяемая подпись, нотариализация и совместимость обновлений.

### Modified Capabilities

Нет: существующих основных спецификаций OpenSpec пока нет.

## Impact

Изменения затронут AppDelegate, AppModel, Preferences/KeyboardEngine, SettingsView, ядро временного состояния и проверки. Для автозапуска используется системный ServiceManagement; минимальная версия macOS 13 сохраняется. Сборочный скрипт уже принимает SIGN_IDENTITY/NOTARY_PROFILE: требуется доработка и проверка, а не создание нового процесса с нуля. Потребуются Developer ID и доступ Apple для реального нотариализованного артефакта; отсутствие доступа блокирует только эту часть выпуска.

OpenSpec и Node.js — инструменты разработки и не входят в приложение. Публикация релиза, отправка команд в удалённую сессию и изменение пользовательского автозапуска во время планирования не выполняются.
