# Spec Delta

## Purpose

Позволяет управлять автозапуском средствами macOS из LSwitcher и сохраняет ненавязчивое поведение приложения при входе пользователя в систему.

## ADDED Requirements

### Requirement: Системное управление автозапуском
Система SHALL предоставлять настройку автозапуска на macOS 13+ и изменять регистрацию только по явному действию пользователя.

#### Scenario: Включение и выключение
- **WHEN** пользователь включает или выключает автозапуск
- **THEN** приложение запрашивает соответствующее изменение у macOS и показывает фактический результат

#### Scenario: Требуется разрешение или возникла ошибка
- **WHEN** macOS требует подтверждения либо отклоняет регистрацию
- **THEN** интерфейс показывает соответствующее состояние и понятное сообщение, а при необходимости предоставляет переход в системные настройки
- **THEN** переключатель не показывает неподтверждённый успех

### Requirement: Отражение системных изменений
Система SHALL считывать фактический статус автозапуска при запуске и возврате к настройкам, включая изменения вне приложения.

#### Scenario: Внешнее изменение
- **WHEN** пользователь меняет разрешение автозапуска в macOS и возвращается в LSwitcher
- **THEN** настройка отражает текущее системное состояние без использования устаревшего локального флага

### Requirement: Поведение запуска
Система SHALL запускаться при входе без окна настроек, открывать настройки при обычном запуске или повторном открытии и сохранять единственный процесс.

#### Scenario: Вход в систему
- **WHEN** macOS запускает зарегистрированное приложение при входе
- **THEN** появляется значок строки меню, а окно настроек не открывается

#### Scenario: Обычный запуск
- **WHEN** пользователь открывает приложение вручную или повторно открывает уже работающий экземпляр
- **THEN** настройки открываются и второй обработчик ввода не создаётся
