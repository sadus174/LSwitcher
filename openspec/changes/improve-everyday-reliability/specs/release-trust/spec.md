# Spec Delta

## Purpose

Определяет проверяемые условия доверенного распространения приложения и обновлений, сохраняя различие между локальной сборкой и нотариализованным выпуском.

## ADDED Requirements

### Requirement: Проверенный нотариализованный выпуск
Процесс выпуска SHALL считать артефакт нотариализованным только после успешной подписи Developer ID, принятия Apple, прикрепления применимого билета и проверки итогового распространяемого артефакта.

#### Scenario: Готовый установщик
- **WHEN** подготовлен выпускной DMG
- **THEN** подписи приложения и вложенного updater проходят проверку, прикреплённый билет валиден и macOS принимает артефакт при проверке политики запуска

#### Scenario: Нет сертификата или доступа
- **WHEN** отсутствует подходящая signing identity, профиль нотариализации либо Apple отклоняет отправку
- **THEN** процесс сообщает конкретный незавершённый этап и не маркирует локальную сборку как нотариализованную
- **THEN** реализация остальных функций и локальная проверка могут продолжаться

### Requirement: Доверенное встроенное обновление
Процесс выпуска SHALL проверять доверие к приложению из ZIP обновления отдельно от DMG, сохраняя проверки закреплённой подписи пакета, SHA256, версии и архитектуры.

#### Scenario: Установка подписанного пакета
- **WHEN** пользователь устанавливает корректный пакет с нотариализованным приложением
- **THEN** updater проверяет пакет и подпись приложения, сохраняет предыдущую копию и устанавливает ожидаемую версию

#### Scenario: Повреждённый пакет
- **WHEN** архив, манифест или подпись пакета изменены либо версия/архитектура недопустимы
- **THEN** установка отклоняется, исходная копия остаётся работоспособной

### Requirement: Достоверное описание результатов
Отчёт выпуска SHALL различать программные проверки, имитацию системных событий, реальные сценарии и подтверждение пользователя; SHALL NOT обещать сохранение разрешений без проверки перехода между сборками.

#### Scenario: Проверка перехода с ad-hoc
- **WHEN** тестируется обновление со старой ad-hoc сборки
- **THEN** отчёт фиксирует фактическое поведение разрешений Accessibility/Input Monitoring и требуемые действия пользователя

#### Scenario: Проверка совместимости
- **WHEN** завершается проверка выпуска
- **THEN** отчёт содержит результаты TextEdit/Safari/Chrome, реального сна/пробуждения и Termius либо явно указанные непроверенные случаи
- **THEN** Spotlight отмечен как проверенный пользователем, а тестовые настройки восстановлены
