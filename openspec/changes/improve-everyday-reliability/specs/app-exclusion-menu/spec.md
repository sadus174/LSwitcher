# Spec Delta

## Purpose

Позволяет управлять автоматическим исправлением для текущего приложения из строки меню, сохраняя доступ к ручному исправлению.

## ADDED Requirements

### Requirement: Управление исключением из меню
Система SHALL показывать название целевого приложения и действие добавления либо снятия его автоматического исключения.

#### Scenario: Добавление и снятие
- **WHEN** пользователь исключает приложение через меню
- **THEN** автоисправление в нём отключается, двойной Shift остаётся доступен, исключение видно в настройках и сохраняется после перезапуска
- **THEN** повторное открытие меню предлагает снятие исключения, возвращающее обычное поведение

### Requirement: Стабильная цель действия
Система SHALL фиксировать приложение при открытии меню и SHALL NOT подменять цель последующей сменой фокуса.

#### Scenario: Фокус изменился
- **WHEN** меню открыто для редактора, а затем фокус переходит другому приложению
- **THEN** действие относится только к редактору, указанному в меню

#### Scenario: Цель недоступна
- **WHEN** целевое приложение не определено, является самим LSwitcher либо завершилось до нажатия
- **THEN** действие недоступно или безопасно отклоняется без изменения исключений

### Requirement: Сохранение защитных ограничений
Система SHALL использовать общий список исключений без дубликатов и SHALL NOT позволять снятию исключения обходить защиту Secure Input и менеджеров паролей.

#### Scenario: Повторное добавление
- **WHEN** приложение уже есть в списке исключений
- **THEN** меню предлагает обратное действие, не создавая вторую запись

#### Scenario: Защищённый ввод
- **WHEN** пользователь изменяет исключения при активном защищённом вводе
- **THEN** обработка защищённого ввода остаётся заблокированной
